Open any file directly in a modern browser.

## Guidelines

- Center content in a max-width 900px container on desktop.
- Support the breakpoints in `docs/design-system/00-tokens.md`
  (`mobile` ≤768px, `tablet` 769–1024px, `desktop` ≥1025px).
- Keep behavior (scroll-snap, keyboard nav, scroll indicator) matching
  `docs/pages/p08-news-listing.md`.
